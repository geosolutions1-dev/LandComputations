# Land Survey App - EPSG:2136

A professional web application for land surveying calculations using the EPSG:2136 coordinate system (Accra Ghana).

## Features

- **Coordinate Input**: Enter coordinates in EPSG:2136 format
- **Automatic Calculations**:
  - Bearing and distance computations
  - Perimeter calculation
  - Area calculation in both Acres and Hectares
- **Parcel Information**: Store owner details, surveyor information, and locality
- **Certificate Generation**: Create professional survey certificates
- **Data Export**: Export survey data to JSON format
- **Sample Data**: Pre-loaded sample data for testing

## Technology Stack

- HTML5
- CSS3 with Bootstrap 5
- JavaScript (ES6+)
- Font Awesome Icons
